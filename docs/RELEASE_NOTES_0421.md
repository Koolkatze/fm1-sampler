# FM1 Sampler 0.42.1 — live sample changes (Android preview)

- LIBRARY remains accessible while editing a pad's sequencer in LOOP/SONG. Select a sequencer lane and browse or select a new WAV, including via the physical PRESETS encoder. The pad keeps playing and its private step pattern is preserved.
- Sequencer sample assignments are project-wide, as in earlier versions; replacing a sample changes that lane's sound in every pattern. SAVE PROJECT persists the assignment and embedded WAV. Existing recorded looper clips are not replaced.
- COMPOSE still restricts recording/editing to free audio tracks so occupied clips cannot be overwritten.
- All 0.42.0 features retained. No project format, package ID or signing identity change. Android versionCode 67. Save a project and backup before upgrading; install over the old app, do not uninstall.
- See [README](../README.md) for controls and [0.42.0 notes](RELEASE_NOTES_042.md) for live pad editing.
