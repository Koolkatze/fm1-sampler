FM1-Sampler Workbench

Mobile-friendly launcher for the original firmware installer. The firmware image has not been modified or rebuilt.

1. Check MIDI + SysEx permission

Use a full Chrome tab on Android. Plug the powered FM-1 into your phone with a USB data/OTG cable and approve Android's USB prompt if shown.

Tap the button to request the required MIDI + SysEx permission.

2. Open the firmware installer

Once MIDI is permitted and the FM-1 is visible, open the original Workbench. Back up samples and projects before flashing. Do not disconnect the USB cable during an update.

Open Workbench Original v0.37 release

If permission is denied

  • Open this page directly in Chrome, not inside ChatGPT, GitHub, or another app's internal browser.
  • Make sure the address begins with https:// and Chrome's site permission for MIDI is not blocked.
  • If Chrome shows a USB access prompt, grant it, then retry with the FM-1 powered on.
  • If no MIDI inputs or outputs appear, try another USB data cable or OTG adapter and reconnect the FM-1.
  • Do not flash until the actual Workbench identifies your device. SysEx permission alone does not prove compatibility.
